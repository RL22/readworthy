User Journeys

Journey 1

"I want to learn how to use Readworthy"

Current path: Home → Guide → (stuck, no clear next step)

After reading the guide, user has no link to the compatibility matrix, CLI reference, or examples.

Journey 2

"I want to understand the philosophy"

Current path: Home → Research Brief → (stranded)

Research pages are isolated. No way to navigate between related concepts without returning to home.

Journey 3

"I want to decide if Readworthy fits my use case"

Current path: Home → Compatibility Matrix → (stuck)

Hard to move from "should we use this?" to "how do we use it?" — no link to guide or examples from compatibility.

Journey 4

"I want to implement the CLI"

Current path: Home → CLI Architecture → (stuck)

Architecture doc exists but no implementation guide, code examples, or integration instructions linked from it.

Issues & Gaps

Pages are flat — no information hierarchy

All pages are at the root level regardless of audience (public-facing vs. internal research). No folder structure signals intent.

Internal documents are in the public nav

Research Brief, Naming Brief, Compatibility matrix, and CLI Architecture are linked from the homepage alongside the Guide. This muddies the product story for new visitors.

No clear learning path

Optimal reading order: Home → Why HTML → Compatibility → Guide → Examples → CLI. Nothing surfaces this path.

Guide does three jobs

"Why Readworthy exists" (argument), "how to structure a document" (how-to), and "component reference" (dictionary) are all in one page. These serve different user intents.

No breadcrumbs

Users have no location signal when deep-linked into a research or reference page. Back button is the only escape.

Recommendations

Priority 1

Folder structure reflecting audience

Move pages into /examples/ and /research/ folders. Public pages stay at root. This is the single highest-leverage change — it makes intent legible without touching content.

Priority 2

Homepage as product page, not portal

Replace the flat card grid with a focused product story: cultural hook (Thariq thread) → what it is → quick start → GitHub star CTA → 3 links (Guide, Examples, Compatibility).

Priority 3

Strip the guide's opening

The "why Readworthy exists" section in guide.html duplicates the homepage. Remove it from the guide and let the guide be a pure reference document.

Priority 4

Examples gallery page

Add /examples/index.html — a brief intro and 4 cards linking to the example documents. Replaces the direct video-summary link in the nav.
