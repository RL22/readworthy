# Product

## Register

brand

## Users

Developers and AI-forward teams currently receiving Markdown outputs from AI
tools. They are building workflows, writing specs, or producing operational
docs and want something more structured and readable than raw MD.

## Product Purpose

Readworthy is a compatibility-first documentation toolkit by Sprintz that helps
teams convert bloated AI-generated docs into structured, scannable, semantic
HTML artifacts. It exists at the intersection of developer tooling and content
craft.

## Brand Personality

An extension of the Sprintz agency brand. Precise, purposeful, opinionated.

## Anti-references

Generic developer-docs blue (GitBook, Mintlify defaults). Bloated SaaS landing
pages. Documentation that looks like it was generated by the same tools it
critiques.

## Design Principles

1. Practice what you preach — the Readworthy site should be an example of
   Readworthy itself: semantic, structured, readable.
2. Show, don't tell — components demonstrate capability rather than describe it.
3. Information before decoration — hierarchy and clarity earn the right to
   visual polish.

## Accessibility & Inclusion

WCAG AA minimum. Readable at any viewport. No motion assumptions.
