What Readworthy Is

Readworthy helps teams keep Markdown where ecosystems expect it, move high-structure operational material into semantic HTML, and style those documents with a tiny adaptable CSS layer. 

.md   = compatibility, discovery, activation
.html = structured operational docs
.css  = presentation layer
